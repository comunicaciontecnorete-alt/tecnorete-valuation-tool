# Requisitos SEO - Fase futura

## Objetivo

Valorar una estrategia SEO específica para las landings de valoración de vivienda por zona.

El usuario quiere estudiar la posibilidad de tener un dominio específico por landing o una estructura SEO individual para cada zona, con el objetivo de captar búsquedas locales.

## Zonas iniciales

- Santa María de Benquerencia
- Santa Teresa
- Toledo Sur
- Azucaica
- Polán
- Layos
- Argés
- Nambroca

## Opciones a valorar

### Opción A - Dominio independiente por zona

Ejemplo:

- cuantovalemipisoensantateresa.com
- cuantovalemicasaenlayos.com
- cuantovalemiviviendaenazucaica.com

Ventaja:

- Puede ser muy específico para campañas.
- Puede tener mensajes muy orientados a una búsqueda concreta.

Inconveniente:

- Más mantenimiento.
- Más dominios que renovar.
- Más configuración técnica.
- Riesgo de duplicar contenidos si las páginas son muy parecidas.
- Más trabajo de SEO para dar autoridad a cada dominio.

### Opción B - Subdominio por zona

Ejemplo:

- santateresa.tecnorete-toledo.com
- layos.tecnorete-toledo.com
- azucaica.tecnorete-toledo.com

Ventaja:

- Separa cada landing.
- Permite estrategia local por zona.

Inconveniente:

- También exige configuración técnica.
- Puede fragmentar autoridad.
- Requiere contenido diferenciado por subdominio.

### Opción C - Un dominio principal con URLs por zona

Ejemplo:

- tecnorete-toledo.com/valora-tu-vivienda/santa-teresa
- tecnorete-toledo.com/valora-tu-vivienda/layos
- tecnorete-toledo.com/valora-tu-vivienda/azucaica

Ventaja:

- Más sencillo de mantener.
- Más limpio técnicamente.
- Mejor para consolidar autoridad.
- Más fácil de escalar.
- Menos riesgo de duplicidades.

Inconveniente:

- Menos agresivo como dominio exacto para campañas.

## Recomendación inicial

Para primera versión, mantener una estructura centralizada.

Más adelante, valorar dominios específicos solo si:

- Hay contenido realmente diferenciado por zona.
- Hay una estrategia clara de SEO local.
- Se van a trabajar enlaces, textos, FAQs y datos específicos.
- Tiene sentido mantener varios dominios.

## Requisitos de contenido SEO por landing

Cada landing debería tener contenido único:

- Titular específico por zona.
- Texto introductorio local.
- Preguntas frecuentes específicas.
- Referencias a tipo de vivienda habitual en la zona.
- Código postal.
- Texto sobre mercado inmobiliario local.
- CTA específico.
- Datos reales o aproximados de precio por metro cuadrado.
- Fecha de actualización del dato.
- Enlaces internos entre zonas cercanas.

## Pendientes técnicos SEO

- Revisar title y meta description por zona.
- Añadir canonical por landing.
- Crear sitemap.
- Crear robots.txt.
- Conectar Search Console.
- Revisar indexación.
- Valorar schema markup.
- Evitar landings duplicadas con el mismo contenido.
